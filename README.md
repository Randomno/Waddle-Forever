# 🐧✨ **Waddle Forever** ✨🐧

💻 **Waddle Forever** is a **localhost Club Penguin emulator** 🧊 that includes:

* 🖥️ A **server emulator** built with Node.js + TypeScript
* ⚡ An **Electron client** that runs the whole game out of the box 🧃

🎯 **Main Goals:**

* ⏱️ *Accessible speedrunning* 🏃‍♂️
* 🏝️ *Accessible sandbox Club Penguin* 🧱
* 📜 *Future goal:* Full singleplayer + party/event archival 🕯️

> 🚨 **[IMPORTANT]**
> 🐧 Grab the downloads here 👉 [🌐 Website Link](https://waddleforever.com/)

# ⚙️ **How It Works** 🧠

🪞 **Two Segments:**

## 🧭 Client

* 🚀 Uses **Electron** to open Club Penguin web pages + run Flash 🔦
* 🧰 Flash installation? → Not your problem 😎
* 🧩 All servers run *inside* the client = plug & play 🪄

## 🌐 Server

* 🧱 Club Penguin server emulator under the hood 🧊
* 🖥️ Can be run **standalone** too — open multiple windows if you like!

> ⚠️ **[CAUTION]**
> 🚫 Not safe for public multiplayer — easily exploitable!
> 🧑‍🤝‍🧑 Only host for trusted friends!
> 🪪 Want a CPPS? → Use something like **Houdini** 🕶️

# 🛠️ **Building the Thing** 🧰

🧩 Requirements:

* 🧑‍💻 Node.js
* 📦 npm
* 🧶 yarn

🧱 **Setup:**

```bash
yarn install
```

📦 **Run Client (dev):**

```bash
yarn start
```

🧩 **Run Server (dev):**

```bash
yarn dev
```

🧊 **Build Game Zips:**

```bash
yarn build-media
yarn build-win
```

🗂️ Output: `zip/` folder 🎁
